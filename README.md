# AKAL V2 — The Living Intelligence

One page. One organism. The visitor watches an intelligent system think:
thousands of weak signals organize — chaos → patterns → connections →
prediction → one undeniable opportunity → one route, one action — and the
site ends looking back at you: *Talk to us.*

**Stack:** Vite + vanilla TypeScript + three.js + Lenis. No framework, no
pre-rendered video — the whole world is three GLSL passes (advected energy
field with liquid-light trails → structure injection → OKLab-graded
composite) plus a CPU swarm of motes and ~120 dendritic thought-nodes.

**Why people come back**
- **Seeded minds** — every visit is a different organism; the URL hash IS the
  world (`#a3f9c1`). The telemetry chip copies a shareable link.
- **Dwell-to-qualify** — in the afterglow, hold the cursor on a thought and
  the system examines it: a dossier types itself, deterministically per seed.
- **Idle life** — go quiet for 8s and the discovery feed proves the mind kept
  working; each event visibly flares the field.
- **Recognition** — `session 003 · signal remembered · you qualified 4 before.`
- **Living tab** — the title thinks too, even in the background.

**Care:** `prefers-reduced-motion` gets a settled, static mind with all copy
readable; mobile gets smaller budgets (motes, field resolution, DPR); an fps
governor drops quality tiers before it ever drops frames. All copy is real
DOM text.

```bash
npm install
npm run dev      # local
npm run build    # tsc + vite → dist/
```
